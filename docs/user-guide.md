# 使用指南

支持 macOS 与 Windows，应用界面为中文。macOS 当前面向 Apple Silicon 本机使用。

拾周把明确的任务和大概时间节点变成每日计划，支持手动调整与完成记录。

## macOS 本机使用

在 Mac 上使用 Node.js 24 LTS 和 npm，运行 `npm ci`、`npm start` 进行开发；运行 `npm run package` 生成 `release/Weekwise-darwin-arm64/Weekwise.app`。双击该应用，或复制到“应用程序”后打开。打包版日常使用不需要 Node.js。当前为本机临时签名构建，没有 Developer ID 签名与 Apple 公证；对外发行需另行配置。

- 主窗口采用系统标题栏。关闭窗口后应用继续在 Dock 与菜单栏运行；点击 Dock 或菜单栏“打开拾周”恢复主窗口。`⌘Q` 或菜单中的“退出拾周”才会完全退出并停止提醒。
- `⌘N` 新建任务，`⌘K` 搜索，`⌘,` 打开设置；复制、粘贴、全选等使用标准 Mac 菜单与快捷键。
- 两种浮窗与提醒窗口设置为显示在各个桌面和全屏空间；多显示器、全屏与台前调度的实际显示效果需要在本机布局中确认。
- 密钥使用 macOS 钥匙串加密；首次使用或应用签名变化时，系统可能请求钥匙串访问许可。请只在应用设置中填写 API 密钥。开发版和打包版的应用身份不同，切换后可能需要重新填写密钥。
- 数据目录为 `~/Library/Application Support/Weekwise`。从 Windows 迁入时导出 JSON 任务备份，再在 Mac 设置中恢复；API 密钥不在备份中，需要重新填写。
- 提醒要求应用运行、电脑处于唤醒状态；不会唤醒睡眠中的 Mac，也不默认开机自启动。

## 开始使用

免安装版位于 `release/Weekwise-win32-x64/`，双击 `Weekwise.exe` 或 `启动拾周.cmd`。整个目录需一起保留；运行不需要 Node.js，也不需要安装依赖。

1. 可以点击「新建任务」，手动填写名称、预计耗时、优先级和截止日期，安排日期可留空；也可以点击「自然语言规划」，直接描述目标。
2. 打开「规划设置与备份」，设置每天可用的分钟数；设为 0 表示休息日。
3. 在设置中填写自己的 DeepSeek API 密钥，会自动加密保存。模型可以直接下拉选择，默认推荐 DeepSeek V4.1 Flash；另可选择 V4 Pro 或自定义名称。
4. 主界面上方两个并排入口：「自然语言规划」用于新增目标，点击「拆分并安排」，预览后添加每日任务；「自然语言调整」用于重排已有安排。
5. 点击右上角「桌面浮窗」。浮窗默认置顶，可以拖动顶部移动、从边缘调整大小、切换日期，点击方框完成任务，确认实际耗时或点击「跳过并完成」后，完成项从浮窗隐藏。
6. 想要更轻的桌面清单，点击右上角「极简浮窗」；也可以在完整浮窗顶部点击叶子图标切换。
7. 组会、面试等固定时间的事项，可以在任务编辑里勾选「定时任务」，填写日期与开始、结束时间，再选择提前多久提醒。
8. 想调整已有安排，点击看板上方「自然语言调整」，描述要求，点击「重排并预览」，检查日期和时长变化后再应用。

自然语言规划和调整需要配置 DeepSeek API 密钥。不配置密钥时仍可手动录入、编辑、拖动和完成任务。「自动规划本周」入口与旧 AI 调用暂时停用，基础规划代码保留。示例任务需要主动添加，正式使用时不会自动生成。

升级后再次启动应用，会检测版本变化并重启后台。关闭主界面后，应用可能仍在托盘运行以提供提醒；需要完全退出时，请使用托盘退出入口。现有任务和 API 配置会保留。

## 设置自动保存

每日时长、类别、基础作息、偏好和 DeepSeek 模型修改后会自动保存，不用再点击保存按钮。输入时稍作停顿即可生效，底部显示保存状态；点击关闭按钮或按 Esc 前会保存最新有效输入。各部分独立保存，未填写完整的类别或无效时段不会阻止其他设置生效；未完成的部分保留上次有效设置。保存失败会保留编辑内容并显示「重试」。

API 密钥填写后自动使用系统加密保存，留空保留已有密钥；删除密钥仍使用「移除密钥」入口。导出备份前会等待待保存设置，恢复后会更新编辑器中的设置值。

## 自定义任务类别

在「规划设置与备份 → 任务类别」编辑默认的工作、运动、生活，或添加自己的类别。新增类别自动选择未被使用的颜色（包含当前还在编辑的类别）。每个类别填写名称、自然语言描述并选颜色；最多30个，也可全部删除关闭标识。删除类别不会删除任务。修改颜色后，所有对应任务和浮窗的色点立即更新。周/月看板上的图例显示颜色与类别名称，悬停查看描述，点击「编辑类别」进入设置。

自然语言规划会把类别定义交给 DeepSeek，根据任务内容选择最适合的类别；不匹配时保持未分类。自然语言调整和当天时段规划也会为尚未分类的相关任务补充类别，预览确认后才保存。已有类别保留，可在任务编辑里手动选择或清除。类别配置和标识随任务备份保存，旧任务不会因升级自行分类。

## 月视图与工作时长

侧栏「计划」中的「月视图」显示整月任务；可点击上方周/月页签，或工具栏右侧的视图按钮切换，可切换上一月、下一月或回到本月。点击日期展开当天清单，支持编辑、打勾、添加、同日排序，以及将当天清单的任务拖到其他日历日期。跨月日期可点击进入对应月份；已完成任务不跨日拖动。当天预计总时长包含已完成和未完成任务。

侧栏「统计」中的「工作时长」包含类似贡献图的年度每日工作时长热图，以及最近7/30/90天的工作时长曲线。默认展示当前年度、最近30天；鼠标悬停查看日期和时长，点击热图或曲线日期展开完成记录，点击记录可以补填或修改实际耗时与实际完成日期。

仅统计已完成任务：填写了实际耗时就使用实际值，未填写则按任务的计划（预计）耗时计入。热图、曲线、总投入、平均时长和每日明细使用同一计算方式，明细标注「按计划耗时计入」，并显示回退项数量。之后补填实际耗时会替换计划值，不重复累加；清除实际耗时会恢复使用计划值。这个回退仅用于统计，不会向实际耗时字段写入计划值。没有完成记录的日期显示0。新完成任务自动记录打勾当天的日期（两种浮窗也适用），与原计划日期独立；旧记录没有完成日期时按安排日期计入，可在编辑中修正。没有日期的旧完成记录不计入，可从「统计 → 已完成」进入补填。取消完成后不计入统计；撤销、备份恢复、其他窗口的完成修改都会同步更新图表。月视图和统计都需点击进入，每次启动默认打开周视图。

## 帮我规划这一天

先在「规划设置与备份」的「一天的基础作息」设置通常的上班/最早开始、下班/最晚结束时间，以及午饭、晚饭、休息等固定空档。默认提供10:30开始、21:00结束、12:00–13:30午饭、18:00–19:30晚饭；都可以修改或删除，还能添加通勤等其他空档。「日常作息补充」可填写休息频率、上午偏好等。

点击看板某一天的「帮我规划这一天」，或工具栏同名按钮（默认今天）。先把要做的任务安排到该日期，功能会按它们的预计耗时规划这一天的具体工作时段；已有定时日程保留，已完成普通任务不会再安排。

「这一天有什么不同，或有什么偏好」可以留空，也可以输入：

> 这一天从8点开始，下午3-5有别的事不能安排任务，晚上8点后不能工作。优先审稿，较长任务可以分段完成。

DeepSeek以基础作息为默认，当天明确要求覆盖对应的日常开始、结束或空档，其他基础规则保留。本地不使用关键词/正则解析这些要求。点击「安排时段」后先预览按时间排列的工作、吃饭休息和固定日程，再点击「应用当天时段」。排不下时只反馈原因和放宽建议，不修改已有安排。

同一任务可分成多段，例如120分钟审稿安排到11:00–12:00和13:30–14:30，仍是一张任务卡片和一个勾选框；它的预计耗时、日期和完成状态不变。建议时段显示在看板卡片与两种浮窗，「今日专注」还会显示完整时间表，包括吃饭休息。工作时段属于建议安排，不会转换成不可移动的定时任务，也不会增加闹钟提醒。原有定时任务的提醒照常工作。

当天可明确允许两项任务同时进行，例如：

> 组会的后一个小时可以用来批改考试题。

DeepSeek理解原话并确定对应任务和具体时段。例如组会15:00–17:00、批改任务需要1小时，可以把批改安排到16:00–17:00，组会仍保留15:00–17:00。也支持明确允许两个普通任务并行。模型需返回具体任务对、重叠时段和引用当天要求的原文许可，本地仅核对引用来源、任务编号及时段一致性，不用关键词解释自然语言。没有明确许可时仍避免任务重叠；许可只适用于对应任务及具体时段，任务各自的预计耗时保留，同一任务不会通过重复重叠时段来减少工作量。吃饭休息和明确不能工作的空档继续保留。

预览和「今日专注」会标明「与某任务同时进行」及具体起止，任务卡片和两种浮窗显示「并行」。应用后两项任务仍独立打勾，固定日程的时间和提醒保持不变。并行许可随当天安排保存到本机及备份；完成、同日排序保留，改变日期、耗时或固定时段仍会清除失效的旧安排。

基础作息只在系统设置里保存；当天例外按日期保存，应用某一天不会改其他日期或基础作息。修改当天输入时，上一次预览保留到再次点击「安排时段」；任务或设置在预览后变化时需要重新生成。应用、清除均可撤销。完成任务、补填实际耗时或同日排序会保留时段；增删当天任务、修改预计耗时、改期或改变固定日程时，会清除受影响日期的旧时间表，避免显示失效的安排，当天例外仍保留以便重新生成。基础作息修改后，可重新生成相应日期的时段。作息、当天例外和时间表包含在本机数据及任务备份中，旧数据继续兼容。

## 用自然语言生成每日小任务

点击「自然语言规划」，例如输入：

> 需要审7篇ICLR稿件。不要集中一天审完，但7天内要审完。一个稿子大概至少1小时，不熟悉的2h。

选择起始日，再点击「拆分并安排」。模型会解释采用的假设、每天审几篇、预留多久，以及截止日期。没有提供不熟悉稿件的数量时，会按每篇较长的 2 小时保守预留，不虚构具体数量。

自然语言理解和排期完全交给 DeepSeek，包括完成状态、章节拆分、休息日、截止日期和耗时估计。本地只提供原始描述、日期、30 天的容量背景和规划偏好，检查返回的数据格式，不使用关键词或正则解释需求，也不另行纠正模型安排。可用容量扣除当天全部已安排任务的预计耗时（包括已完成任务）后提供给模型作为参考。

也可以输入「我还需要改一篇稿子，Intro已经改完了。Related work，Method，和Experiments，Conclusion还没改。你规划一下，但我今天不想改了。这周内完成」。提示模型按未完成章节拆分、跳过 Intro、明天开始、本周日截止；没提供耗时时让模型合理估计并说明假设，预览后可自行修改。

预览后添加，每条每日任务可单独打勾，例如「审 ICLR 稿件 · 2篇」或「修改 Related work 和 Method」。数量是否完整、如何合并每天的任务由模型负责；添加前可在预览中检查安排。每日任务默认带锁定日期标记；普通任务仍可拖动或自然语言调整，也可在卡片中编辑日期、耗时或取消标记。勾选今天这一条不会把其他天的任务一起完成。

修改原始描述或起始日时，会保留上一次的完整规划，方便对照调整输入；「添加每日任务」暂时禁用，直到再次点击「拆分并安排」生成新结果。点击生成时才替换旧预览；生成期间修改输入会取消当前请求。已有任务在生成过程中发生变化时也需要重新生成。添加一批每日任务后可用通知中的「撤销」撤回整批添加。

## 用自然语言调整已有规划

点击看板上方「自然语言调整」，例如输入：

> 周天我想把总工作时长压缩到2h，其它任务往后排，定时任务不能动。如果后面排不下，请告诉我需要放宽哪些条件。

「周日」以当前看板所选周为参考，界面会显示参考范围；可以在「最晚可以安排到」指定允许顺延的范围，默认约 30 天，最多未来 90 天。DeepSeek 接收现有未完成普通任务、固定日程、每日时长和截止日期，决定哪些任务需要跨天或跨周移动。普通任务即使先前锁定也允许重排；定时任务默认保持原安排，用户明确要求修改某个日程时，可同时修改日期和开始、结束时刻；提醒提前量保留并按新时间触发。已完成任务保持原样，普通任务名称、耗时、截止日期及拆分来源也保留。

单次「周日 2h」作为指定日期的独立上限保存，不改变每周日的默认设置；预览会显示原时长 → 新时长、每条移动任务的原日期 → 新日期，以及相关日期的总时长。总时长包括定时事件和当天已完成任务。应用后，看板与浮窗同步更新；通知中的「撤销」同时恢复任务日期和单日时长设置。可以再次描述「恢复 10 月 11 日的默认可用时长」来清除该日期的独立设置。

如果固定日程已经超出新上限，或者后续可用时间、任务截止日期不允许顺延，模型会返回原因及放宽条件的建议。此时「应用调整」禁用，现有任务和时长设置不改变。可以手动延长任务截止日期、扩大可安排范围，或在新的调整要求中明确允许增加某日时长，再重新生成。模型不会通过偷偷延长截止日期、缩短普通任务耗时、擅自移走未被要求修改的定时事项或丢弃任务来满足要求。

理解要求、判断是否可行和排期都交给 DeepSeek，本地只检查结果格式和任务标识、保护已完成任务及未返回调整的日程。单次最多调整 200 条未完成普通任务。编辑描述或范围时，上一次预览仍保留，直到再次点击生成；已有任务在生成或预览后发生变化时，需要重新生成，以免覆盖新修改。

例如「面试调整到明天下午2-3」：以本机今天为参考解释明天，与看板参考周无关；预览显示原日期和时段 → 新日期和时段，确认后再修改。只改时段也会显示在预览中，预计耗时随时段长度更新，提前半天、2小时、半小时的提醒自动跟随新的开始时刻。如果定时任务截止日期与原日程日期相同，改期时同步到新日期；独立的截止日期保持原样。其他定时日程不自动挪动，名称、备注、完成记录和提醒提前量保留。应用后可撤销日期、时段和时长变化。

## 定时任务与闹钟提醒

在「新建任务」或任务编辑中，先选安排日期，勾选「定时任务」，再填写当天的开始、结束时间。例如组会 15:00–17:00、面试 19:00–20:00。预计耗时会随时段计算，日期自动锁定，自然语言调整默认保留定时安排，明确要求时可修改日期和时段；你仍可手动修改或拖到其他日期，时间段会保留。

可分别勾选提前半天（12 小时）、2 小时、30 分钟，或开始时提醒；默认前三项勾选。提醒相对开始时间计算，能够跨日，每个时间点独立提醒一次。取消所有提醒选项可只记录时段。点击「试响一下」可以立即验证弹窗和本机声音，显示编辑框当前填写的任务日期与开始、结束时间，包括未保存的修改。试响不保存任务、不修改正式提醒记录；需先填写有效日期和同一天至少5分钟的时段。

也支持直接描述，例如：「明天下午3-5是组会，晚上7-8是面试，提前半天、2h和半小时分别提醒一下。」由 DeepSeek 解释日期、时刻和提前量，预览中会显示时段和提醒，添加后进入本机提醒。无固定时段的任务仍按原来的每日待办方式处理。

提醒通过置顶弹窗和约 15 秒的提示音触发，点击「知道了」停止声音并关闭，或点击「打开计划」。声音使用系统当前音量；静音时弹窗仍显示。多个同时到达的事项在同一个提醒窗中列出。完成、删除、取消提醒或改期后，原安排的待触发提醒会取消。

有尚未结束、启用了提醒的任务时，关闭主窗口和浮窗后，拾周会留在系统托盘继续运行。点击托盘图标可打开主界面，右键可选择「退出拾周（停止提醒）」。Windows 无待提醒事项时，关闭全部窗口仍会退出；macOS 关闭全部窗口后仍保留后台，需主动退出。需要电脑开机且拾周正在运行；本版本不会唤醒休眠电脑，也不自动随 Windows 启动。重新打开或从休眠恢复时，错过的多个提前点会合并为一次当前仍有用的提醒，已经结束的事项不再补响。时间按本机日期与时区计算。

提醒发送记录保存到本机 `reminders-fired.json`，用于重启后去重；任务备份包含时段和提醒设置。定时任务需要安排日期，移回「待安排」前应先在编辑中取消定时设置。

## 日常调整

### 极简透明浮窗

极简浮窗的窗口背景完全透明，默认靠在桌面左上角，顶部留出 96 个逻辑像素避免遮挡顶部栏，只显示今天的任务名称和勾选框，任务块使用半透明底色保证阅读。日期、进度、预计耗时和底部文字都隐藏；窗口自动适应约四条任务的高度，向下扩展，任务较多时可滚动查看。完整浮窗也默认放在此位置。升级时，之前未移动的右侧默认位置会迁移到左上角；其他保存位置继续保留。

按住任务块的文字区域或鼠标靠近时出现的拖动把手，可以移动整个浮窗；勾选框仍可直接点击，完成后任务从浮窗隐藏，完成状态与看板同步；在主界面取消完成后会重新出现在浮窗。完整浮窗的完成进度仍按当天全部任务计算。鼠标靠近时，顶部出现切回完整浮窗、打开主窗口和关闭浮窗的小图标。主窗口关闭后浮窗仍可使用，外观模式和各自位置保存在本机，下次打开会恢复。透明模式使用固定宽度与自动高度，完整浮窗仍支持从边缘调整大小。

### 每日总时长与实际耗时

看板每天的总时长是当天已完成与未完成任务的预计耗时之和。勾选完成不减少总时长，也不改变每日负荷条；顶部「本周待投入」仍只统计未完成任务。实际耗时单独记录，不替换预计耗时。

在主界面、完整浮窗或极简浮窗点击完成时，会提示填写实际耗时（分钟）。点击「保存并完成」一并保存完成状态和耗时；「跳过并完成」只保存完成状态，工作时长统计先按计划耗时计入，实际耗时字段仍留空。点击取消或按 Esc 保持待完成。完成记录显示在主界面的卡片里；点击卡片可补填、修改或清除实际耗时。取消完成会保留记录，下一次完成时可修改；跳过会清除旧记录。极简浮窗录入时临时展开，结束后恢复清单高度。实际耗时随任务保存到本机及备份中，已有任务和旧备份无需迁移。

### 看板与任务

在同一天内，将任务卡片拖到另一张卡片上半部或下半部即可调整显示顺序，紫色插入线标记放置位置；拖到该日下方空白处会放到末尾。已完成任务仍在当天清单下方，也可以在已完成任务之间排序；它们不会被拖到其他日期。同日排序只改变显示位置，定时任务时段、提醒和每天总时长保持原样。顺序自动保存在本机，重新打开、备份恢复及自然语言调整后仍保留，并同步到两种浮窗。排序后可使用「撤销」恢复。跨日拖动也可放到指定任务前后。

- 点击任务卡片可编辑名称、耗时、截止日期、安排日期、优先级和备注。
- 在看板中按住未完成任务卡片，拖到另一日期列即可调整日期，自动生成并锁定的每日任务也可以直接拖动。移动到其他日期时保留原来的锁定状态；拖回下方「待安排」会清除日期和锁定。移动后可以撤销。
- 锁定日期标记保留，普通任务仍可手动编辑、拖动或自然语言调整。
- 「自然语言调整」允许跨周移动普通任务，也支持明确修改定时任务日期和时段，保留已完成任务；需要拆分新目标时使用「自然语言规划」。
- 浮窗和主界面同步完成状态。关闭主窗口时，已打开的浮窗继续运行；可从浮窗重新打开完整计划。有待提醒事项时，关闭全部窗口后继续在托盘运行；Windows 没有时退出应用；macOS 仍保留后台。
- 修改任务、规划、恢复备份后，通知中可撤销最后一次修改。浮窗发生修改后会清除旧的撤销记录，以免覆盖新的状态。
- `N` 新建任务，`Ctrl+K` 搜索；每周前后切换可规划未来周。

## 选择 DeepSeek 模型

设置中的「选择模型」提供两个官方当前支持的选项：

- **DeepSeek V4.1 Flash**（`deepseek-flash`）：本应用推荐用于日常任务规划，API 费用较低。
- **DeepSeek V4 Pro**（`deepseek-v4-pro`）：作为另一种规划结果的备选，API 费用高于 Flash。

模型名称根据 [DeepSeek 官方接口文档](https://api-docs.deepseek.com/en/) 与 [价格文档](https://api-docs.deepseek.com/quick_start/pricing/) 于 2026-10-08 核对。两者均支持本应用使用的 JSON 输出；本应用使用非思考模式。保留「自定义模型名称」，已有自定义配置不会被覆盖。切换模型时，密钥留空即可保留已保存的密钥，选好后会自动保存。

## AI、数据与备份

调用 DeepSeek 使用你自己的 API 账户额度。「帮我规划这一天」会发送所选日期、基础作息、日常补充和当天例外、该日未完成普通任务的名称/预计耗时/优先级/截止日期/最多1000字符备注，以及当天定时日程名称和时段；不发送API密钥到模型上下文、其他日期任务或实际耗时记录。「自动规划本周」已暂停，不会发起该接口的请求。自然语言拆分时发送你的描述、起始日、每天可用时长及规划偏好，已有任务只通过每日已占用分钟数体现，不发送其标题或备注。自然语言调整时发送你的要求、参考周、可安排范围、全部未完成普通任务的标题、备注（最多前 1000 字）、耗时、截止日期、现有安排和来源信息，以及未完成定时事件的标题、日期、时段和提醒设置；已完成任务仅通过每天占用分钟数体现。关闭预览会取消本机等待；服务商可能已经处理的请求仍可能计费。

密钥使用 Electron `safeStorage` 通过 Windows DPAPI 或 macOS 钥匙串加密保存在本机，不返回前端、不包含在任务备份中。默认数据位置：

```text
%APPDATA%\Weekwise\tasks.json
%APPDATA%\Weekwise\ai-config.json
```

任务使用文件替换方式保存，并检查并发修改冲突。数据损坏时会提示错误并暂停编辑，不会静默清空。可从设置导出 JSON 备份；恢复备份会替换任务和规划设置，API 密钥不受影响。

AI 使用每次请求独立的短编号识别任务。「自然语言调整」中已完成任务不可改，定时任务默认保留、明确要求时通过独立的定时调整列表修改。普通任务必须完整且恰好出现一次，不能将已安排任务清空来假装腾出了时间。未知编号、遗漏任务或格式问题会请求校正一次（最多两次 API 调用，均使用账户额度），再次不合格时显示原因并保留当前任务。API 超时、密钥错误、余额不足等会显示提示，可以在配置修正后重新生成。**真实 DeepSeek 调用需要配置有效密钥；开发验证使用模拟响应，没有消耗真实 API 额度。**

接口依据 [DeepSeek 首次调用文档](https://api-docs.deepseek.com/en/) 和 [JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)。密钥保存机制参考 [Electron safeStorage 文档](https://www.electronjs.org/docs/latest/api/safe-storage)。

## 开发与验证

需要 Node.js 和 npm：

```powershell
npm install
npm start
npm test
npm run package
```

若 npm 未下载 Electron 二进制，执行 `node node_modules/electron/install.js`。浏览器预览使用 `npm run preview`，打开 `http://127.0.0.1:4173`；浏览器预览用于手动任务管理，AI 规划、密钥及原生浮窗在桌面客户端中使用。`?demo=1` 是不保存数据的示例预览。

`npm test` 覆盖日期边界、截止日期、容量、锁定与跨周任务、备份校验、原子保存、并发冲突及模拟 AI 响应，也验证自然语言规划只传递原文与占用背景、支持按章节拆分单篇稿子、不再本地纠正模型排期，以及旧分类数据兼容。自然语言调整测试覆盖完整任务标识、跨周移动、固定事件和提醒保留、单日时长设置及恢复、不够时间时无部分应用、格式修正请求。

`scripts/smoke.cjs`、`scripts/smoke-natural.cjs`、`scripts/smoke-compact.cjs`、`scripts/smoke-reminders.cjs` 和 `scripts/smoke-replan.cjs` 是桌面端到端验证，需 Playwright；可通过 `PLAYWRIGHT_MODULE` 指定含 Playwright 的 `node_modules` 目录。它们使用 `test-results/` 下独立数据，验证任务编辑、旧本周接口暂停、撤销、浮窗同步、主窗口重开、密钥加密、自然语言每日任务、锁定卡片拖动、透明窗口，以及模拟时钟下的三次闹钟、关闭窗口后后台触发、提示音生成和自然语言定时事件。调整测试还验证预览不改数据、保留旧预览、应用与撤销单日时长、跨周任务、浮窗同步、预览后的并发修改保护和不可行反馈，并生成界面截图。提醒测试使用静音参数，不干扰本机声音。`WEEKWISE_EXECUTABLE` 可指定打包的 `Weekwise.exe` 进行发行版验证。

技术结构：Electron 主进程负责文件、API 和窗口；沙箱渲染进程负责界面。使用本地自定义协议、隔离的 preload 接口、内容安全策略和输入校验，界面无需外部网络资源。

运行 `npm run test:desktop` 可顺序执行桌面验证；macOS 额外覆盖菜单、Command 快捷键、Dock 重开、关窗后台、备份和钥匙串重启读取。可通过 `WEEKWISE_EXECUTABLE` 指向 `.app/Contents/MacOS/Weekwise` 测试打包版本。测试使用独立数据和假密钥，不消耗 AI 额度。
