# Changelog

## v0.1.0

首个 GitHub 基线版本 / First GitHub baseline.

- 自然语言拆分、重排与每日时段规划 / Natural-language task breakdown, rescheduling, and daily time planning.
- 周／月看板、拖动排序与自定义颜色类别 / Weekly/monthly boards, drag-and-drop ordering, and custom color categories.
- 完整／透明桌面浮窗与定时提醒 / Full/minimal desktop widgets and scheduled reminders.
- 实际耗时、工作热图和趋势曲线 / Actual time tracking, activity heatmap, and work-time trends.
- 本机数据、备份与设置自动保存 / Local data, backups, and automatic settings saving.

此前本地开发版本统一以 v0.1.0 作为 GitHub 迭代起点；现有任务数据和配置继续兼容。
Earlier local development builds are consolidated into v0.1.0. Existing task data and settings remain compatible.
